How I can help you

Whether you’re a founder with an idea, a team that needs another senior developer, or a company whose app is starting to creak, here’s where I can step in.

  • App development

    Native apps for iPhone, iPad and Apple TV in Swift and SwiftUI, plus React Native when you need Android too. From first build to App Store release.

  • Web development

    Web apps, dashboards and admin panels in React and TypeScript, built to work hand in hand with your mobile app.

  • Backend and APIs

    REST APIs and databases in PHP and MySQL, with AWS and Firebase for hosting, sign-in and push notifications.

  • Product development

    For founders: from idea to a first version in people’s hands. I scope it with you, build it end to end and launch it.

  • Product discussions

    A call to pressure-test an idea, pick a tech stack, plan an MVP or sanity-check an estimate, with someone who has run a company.

  • Code reviews and audits

    Pull request reviews, full codebase audits, and plans for moving Objective-C to Swift and SwiftUI.

  • Performance improvements

    Faster launches, smoother scrolling, fewer crashes and lower memory use, found with Instruments rather than guesswork.

  • Tech lead and mentoring

    Leading a mobile team, setting up reviews and release processes, and helping junior developers grow.
